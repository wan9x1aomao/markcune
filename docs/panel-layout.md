# 文件与大纲布局

4.1.0 起，工具栏「布局」与「设置 → 界面」提供同一组面板偏好，选择立即生效。

- **左右分栏：**文件在左、大纲在右，保留原来的默认位置与显示状态。
- **反向分栏：**大纲在左、文件在右。
- **集中在左／右：**两个面板放在同一侧，默认上下分区；可交换上下，或改用文件／大纲标签切换。

拖动侧栏与正文之间的边界调整宽度，上下分区时拖动两块面板之间的分隔线调整比例。也可聚焦分隔线后按方向键调整。

文件列表与大纲仍可分别显示或隐藏，原有快捷键保持为 `⌘⇧L` 与 `⌘⇧T`（Windows / Linux 为 Ctrl）。同侧使用标签时，点击大纲工具栏按钮可先切到大纲标签。

布局、宽度、上下顺序、比例与当前标签会保存在本机。窗口变窄时只临时收起面板，点击文件或大纲按钮展开；窗口恢复后沿用原来的排列与宽度，不会覆盖用户选择。专注模式也只临时收起面板。

重排过程中不重新创建编辑器和文件树，文稿、光标、阅读位置、置顶文件及展开状态保留。界面沿用应用现有的字体、悬浮面板、圆角、图标和明暗主题变量。

实现：`src/panel-layout-model.js` 负责纯布局计算和偏好规范化，`src/panel-layout.js` 负责面板与统一设置入口，`src/panel-layout.css` 复用现有设计变量。`npm test` 检查布局模型；`npm run test:layout` 使用隔离的真实编辑器验证交互、阅读位置与持久化，不访问用户文件。
