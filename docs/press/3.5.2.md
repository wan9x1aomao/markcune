# MDPad 3.5 发布：本地 Markdown 编辑器加入语音输入与 AI 整理

**6 MB、免费、MIT 开源；不登录、不上传；AI 与语音都需要你自己的 Key，默认关闭**

2026 年 10 月 20 日 —— 本地 Markdown 编辑器 MDPad 今日发布 3.5 版本。

这一版加入**语音输入**：点右下角的麦克风直接说话，文字落在光标处，最长 120 秒；说错了按 `Esc`，一个字都不会进文件。录音由应用自己完成，不弹浏览器权限框，语音与 AI 的 Key 分开保存。

「一键整理」也升了一级：填入自己的 AI Key 后，由模型判断哪些行是标题、列表和引用，长文会自动分段；没填 Key 时退回规则整理，功能照常可用。「从链接打开」开始支持 X 帖子和长文，正文、图片与标题结构一并存进本地书库。此外，文件列表支持置顶常用文档，换文件夹也不会消失。

MDPad 要解决的问题一直很小：**AI 产出的 .md 越来越多，但「能打开」和「能读」是两件事**。用系统自带的文本编辑器打开，是一屏井号、星号和竖线；专业的 Markdown 编辑器大多收费；IDE 也能读，但为了一份笔记启动整套开发环境，并不划算。

MDPad 的做法是把这件事做小：安装包 6 MB 左右，三个平台功能一致，双击文件就是一篇排好版的文档，没有登录、没有云同步、没有插件市场。所见即所得，`⌘/` 切到源码，`⌥⌘/` 分屏对照；文件夹、大纲、命令面板、停笔自动保存、代码高亮、LaTeX 公式、Mermaid 流程图，以及导出网页、Word 和 PDF。

所有 AI 能力都遵循同一条原则：**只提建议，采纳才落笔**。续写以灰字浮出，`Tab` 收下、`Esc` 忽略；改写以「原文划掉、新文绿字」对照呈现，点「采纳」才会写进文件。Key 只存在本机，界面读不回来；文字直接发到用户填写的地址，MDPad 不做中转；不填 Key 时，这些入口完全不出现。

「我希望它轻量、简单，几乎感觉不到它存在，但该有的都有。」MDPad 的作者说。

MDPad 采用 MIT 许可，源码在 GitHub 公开，可自行编译，也可直接下载安装。

**关于 MDPad**

MDPad 是一款本地 Markdown 编辑器，面向需要频繁阅读和整理 `.md` 文件的用户。它不做云同步、不设账号体系，文字和图片都保存在用户自己的设备上；AI 与语音能力均默认关闭，由用户自行接入服务商，输入内容直接发往用户填写的地址。
