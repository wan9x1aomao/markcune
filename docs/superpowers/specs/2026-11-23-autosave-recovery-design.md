# 自动保存误删恢复设计

## 目标

编辑器继续自动保存，同时保证误删内容在当前会话和重启后都能恢复。

## 方案

保存正式文档前先保存上一份内容到应用数据目录的滚动历史。清空文档或单次删除大段内容时，自动保存延迟五秒并显示撤销与立即保存入口。历史恢复会把版本载入编辑器并作为新的未保存修改处理。

## 范围

本轮覆盖已保存文档和未命名草稿，保留现有编辑器撤销栈、原子写入和外部修改冲突检测。历史保留最近 20 份去重快照。

## 验收

- 大段删除不会在一秒后无提示地覆盖正式文件。
- 用户可以立即撤销删除，也可以选择继续保存。
- 应用重启后可以通过恢复入口载入最近一次保存前的版本。
- 普通小幅编辑保持现有一秒自动保存行为。
- 历史快照写入失败不会破坏现有保存链路。
