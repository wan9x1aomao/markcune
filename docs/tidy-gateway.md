# 一键整理：网关接口约定

mdpad 里没有任何模型、Key 或提示词的配置。整理时只向网关发一个请求，模型和提示词都由网关决定。

> 现成的实现：[`gateway/tidy-gateway.mjs`](../gateway/tidy-gateway.mjs)（零依赖 Node，任何 OpenAI 兼容接口都能接）。
> 怎么跑、怎么接到应用、放在哪里、失败时会怎样，见 [`gateway/README.md`](../gateway/README.md)。

## 地址

- 运行时：环境变量 `MDPAD_TIDY_URL`（优先）。
- 构建时：`MDPAD_TIDY_URL=https://你的网关/tidy npm run build` 把地址固定进应用。
- 必须是 `https://`（本机调试可以用 `http://localhost` 或 `http://127.0.0.1`）。
- 没有配置时，悬浮按钮只在规则能整理出结构时才出现，整理只走规则。

## 请求

`POST <MDPAD_TIDY_URL>`，`Content-Type: application/json`

```json
{ "lines": ["项目周报", "", "一、本周进展", "完成了登录页面"] }
```

- 一次最多 400 行、3 万字；更长的文档由应用分块，每块一次请求。
- 应用不发 Key。如果网关需要鉴权，请放在网络层（内网、IP 白名单、mTLS 等）；
  参考实现另外支持 `TIDY_TOKEN`，并且**监听非回环地址时不设它就直接拒绝启动**。
- 参考实现只处理 `Content-Type: application/json`（其他返回 415），`Origin` 与本机 `Host`
  对不上的请求返回 403 —— 否则浏览器里随便一个网页都能借用户的机器刷你的模型额度。

## 响应

```json
{ "labels": ["h1", "blank", "h2", "p"] }
```

- 直接返回数组也可以。
- `labels` 的长度必须等于 `lines`，每一项只能是下面之一，大小写不限：

| 标签 | 含义 |
|---|---|
| `h1` `h2` `h3` | 文档标题 / 章节标题 / 小节标题 |
| `ul` `ol` | 无序 / 有序列表项（应用会去掉原来的符号并换成标准写法） |
| `quote` | 引用 |
| `p` | 正文段落 |
| `cont` | 上一行被换行打断的后半句，会并入上一行 |
| `blank` | 空行：**空行必须标 blank，非空行不能标 blank** |
| `keep` | 本来就是 Markdown 的行，保持原样 |

- 失败时返回非 2xx，并带 `{"error":{"message":"…"}}`，信息会显示给用户。
- 超时 60 秒。

## 应用端的保护

- 网关只给标签，不返回文字，所以不可能改动、漏掉或编造原文。
- 标签数量不对、出现未知标签、空行和非空行对不上，都会被拒绝，这一块退回规则整理。
- 整理前后再核对一次文字，不一致就放弃，原文不动。
- 整理是一次编辑，撤销一步恢复。

## 给网关的提示词参考

> 你是文档排版助手。下面是一段没有排版的纯文本，每行前面是行号和制表符。请给每一行打一个标签，只输出一个 JSON 字符串数组，长度必须等于行数。标签只能是：h1、h2、h3、ul、ol、quote、p、cont、blank、keep。空行必须标 blank，非空行不能标 blank。不要修改、翻译、总结文字，你只打标签。
